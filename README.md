🎂 Doce Vida — Aplicação Web (React + TypeScript)

Uma aplicação web moderna, elegante e responsiva desenvolvida para a doceria artesanal Doce Vida. O projeto conta com design em modo escuro (Dark Mode), navegação fluida em estrutura SPA (Single Page Application) e uma paleta de cores sofisticada em tons de roxo e preto.
